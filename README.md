# DUO — instrument collection

Eleven browser-local, dual-surface instruments based on the supplied reference video. Signal remains the default entry point, with its saved appearance, sound and camera settings intact. Open the grid icon in the footer to switch instruments. The ten new instruments are grouped into three batches for device testing and can also be opened directly at `collection.html#carrier` (replace `carrier` with an ID below).

The app is served directly from the repository root. No build step, package installation or remote asset requests are required.

## Collection and testing batches

| Batch | Instrument / URL ID | Main interaction |
| --- | --- | --- |
| 01 | Carrier / Modulator · `carrier` | Left radius selects scale degree, angle selects octave. Right radius changes FM ratio, angle changes modulation index. Both hands control the same sounding voices. |
| 01 | Cellular Field · `cellular` | Independent contacts create faceted voices. Move across pitch and octave; the right field changes filter cutoff and detune. The curtain displays the measured spectrum. |
| 01 | Cell Census · `census` | Touch hexes to play or edit the sequence route. Drag translucent timbre regions by their headers. Region placement changes the sound of cells beneath them. |
| 02 | Machine / Swarm · `swarm` | Edit pitch lanes; drag the moving streak field to play and physically disturb its flow. Translate and spread affect tuning and gesture response. |
| 02 | Graticule / Lissajous · `graticule` | Left angle selects pitch, radius selects octave. Right X/Y changes frequency ratio and FM index, plotted as a three-dimensional phase figure. |
| 02 | Machine / Man · `waveform` | Tap sequence cards to enable or mute them; drag to change pitch. Shape the sampled and continuous waveform surfaces. |
| 03 | GeoSynth · `geo` | Play the note map and its coloured timbre regions. The right terrain can be played, orbited and pinched without confusing navigation with a note gesture. |
| 03 | Hand / Machine · `hand` | Play the keys or shape the upper hand surface. The right side exposes voice envelopes, measured scope traces and ASCII amplitude. |
| 03 | Structural Score · `structure` | Edit the truss nodes or pitch rows. Play the purple spectral loop; drag its surrounding space to orbit and pinch to zoom. |
| 03 | Past / Future · `granular` | Scrub source position and grain pitch across history, cloud and future fields. Import local audio or use the internal harmonic buffer. |

All ten ship together. Each has independent sound, visual settings and editable data, stored locally. Sound and Appearance are independent draggable panels; Appearance groups controls by the object they affect. Save a named look, reset to Reference, undo changes, or export/import the current instrument's JSON. Exports are instrument-specific. They do not contain imported audio files: a granular source survives instrument switches within the tab, but must be reimported after a page reload. Imports accept browser-decodable audio under 64 MB and two minutes.

The collection uses native Web Audio FM voices, sample-clock sequencing, per-contact Hold/Arp, bounded polyphony, output limiting and post-output metering. Granular uses actual overlapping, windowed buffer grains with a bounded pool, routed through the same output meter. Three.js renders the cellular bodies, harmonic phase plot, terrain, spectral loop and grain cloud. Canvas draws the remaining fields and technical annotations. Signal retains its existing Tone.js engine and renderer.

For each batch, test two-finger playing with Hold/Arp, tempo scrubbing, sound and appearance changes while a note is held, rotation/resize, and returning to a saved instrument. Pausing a sequence leaves held contacts sounding; turn Hold off to release them. Escape releases notes when no panel or disclosure is open. Backgrounding the app or leaving an instrument silences it. A–K plays collection voices, except Past / Future, whose touch surfaces control the grain engine.

The PWA caches Signal and the complete collection. An update waits until the instrument is idle before activating. Installed iOS audio interruptions, touch callouts, system chrome and hardware frame rate still require testing on the device; desktop browser emulation does not reproduce those OS behaviors.

## Local development

Run `npm start` or `python3 -m http.server 4173` from the repository root, then open http://localhost:4173/. Run `npm test` with Node.js 22 or newer. Runtime JavaScript, styles, icons and bundled libraries are tracked at the root; regression tests are in `tests/`. Sound, sequences, and visual settings save on the current device. Appearance looks can be exported.

## Installed display and touch

The manifest requests fullscreen, falling back to standalone where the browser does not support it. Appearance → Shared → Layout also offers Enter/Exit fullscreen when the browser exposes a usable Fullscreen API. It follows browser-driven exits and does not offer a redundant action in an already-fullscreen installed window. iOS controls its own status indicators and may keep them visible; CSS cannot force them away. The app retains `viewport-fit=cover` and safe-area insets so controls avoid system overlays. Installed manifest changes may require the OS to refresh the installation.

Holding an instrument control or label does not select text or open the WebKit touch callout. Text-entry fields retain selection and editing. Actual iOS magnifier and installed display behavior still need device verification; portable browser checks do not emulate the OS chrome.

## Playing Signal

- Drag the ring to play scale-locked pitches; moving outward raises the octave. Start a drag in empty space around the ring to orbit freely through full rotations, with eased momentum. Scroll in empty space or pinch with two touches that start there to zoom. A touch that starts on the ring remains a playing touch. Arrow keys orbit a focused ring; +/− zoom; Home or a double-click in empty space resets the fitted view. Camera position and zoom save separately from appearance. Picking uses the visible 3D surface and current camera/rotation/scale. A contact reticle, illuminated bead patch and live voice arc attach to the touched ring surface and follow it through rotation, orbit and zoom. Moving the playing pointer selects a new surface point. Decorative ring elements do not intercept touches.
- In Filter Sky, drag to orbit freely through full rotations, Shift/right-drag or Pan to translate, and scroll/pinch or use +/− to zoom. The Z-depth readout has a fixed width so changing detune values cannot shift its slider. Tune or drag the reticle to move its 3D position; picking a landmark selects its location. X maps logarithmically to cutoff, Y to resonance, and Z to oscillator detune/spread. The depth slider and Page Up/Down adjust Z; arrow keys adjust X/Y. Camera navigation does not change sound, and the view persists locally.
- Drag sequence steps vertically to change pitch; tap to toggle; shift-drag for velocity.
- A–K plays notes. Space starts/stops the sequencer. Escape closes the front settings panel first; with no settings open, it releases all notes.
- The footer holds play/pause, tempo, Arp and Hold icons, and a key/scale disclosure. Press and hold the tempo readout to reveal its horizontal slider; move left or right with the same pointer to change BPM and release to collapse it. The adjustment is relative, so pressing never jumps the tempo. Arrow keys adjust by one, Shift+Arrow or Page keys by ten, and Home/End select the limits. Open the key control for root, scale, arp rate and direction. Sound and Appearance use icon buttons and independent floating panels: both can stay open while playing or adjusting the other panel. Drag a title bar to reposition it; its close button closes only that panel. The footer toggle raises an obscured panel or closes the front panel. Placement and open state save locally, and the panels stay within the visible screen when the viewport changes. The Performance disclosure retains outside-tap dismissal. Hold latches played ring and keyboard notes; Arp cycles the held notes at the selected rate. Turning Hold off releases only latched notes, and pausing the sequence leaves held and arpeggiated notes sounding. Musical keys remain available after operating a button; text fields and native control shortcuts keep their normal behavior. A second finger can operate the performance, footer and waveform buttons while the first keeps playing.
- Appearance groups its controls by Galaxy, Ring, Particles and Shared settings, with only the current surface’s categories shown. Shared settings contain colors, typography, layout and the guide opacity/spacing that affect both scenes. Visual presets, saved looks and history remain available. Category tools expose locks and reset; the bottom row holds A/B and Freeze. Tools reveals seeded mutation, phase, seed, and look import/export. Each control includes an affected-area description. Microcopy controls map annotations and section labels, including visibility, monospace text size and spacing. Numeric parameter readouts remain visible. Decorative captions and scene titles are omitted.

## Signal language

Signal uses the owner-supplied appearance: black plots, pink notes and magenta particles, with dense beads, broad particle bloom and grain in the ring finish. Its geometry, motion, matrix, lighting, labels and color settings match the imported Signal look. New sessions and Appearance resets use these values. Untouched revision-5 Signal sessions upgrade; customized looks, sound, sequence and camera settings are retained. Other visual presets remain available. The ring’s WebGL output and main UI panels are transparent so they do not cut off the shared lines.

- White arcs connect the filter hub to active voice locations. Accent-colored arcs originate at the sequence step that actually triggered each voice. Each arc and ring highlight follows that voice’s actual amplitude envelope, including release.
- Pointer-triggered arpeggio pulses carry their originating gesture through audio scheduling and pooled voice reuse. Their bead highlights and white arc endpoints follow that touch, including moving contacts and latched Hold notes. Keyboard and sequencer notes retain their voice-sector indicators.
- Matrix paths originate at the projected 3D galaxy crosshair and converge at the ring’s geometric center. Moving emissions are rasterized into a fixed low-resolution grid, then each lit cell is drawn as a square, circle or ASCII character with adjustable spacing, gap, exposure, contrast and cutoff. Dots support brightness-dependent size; ASCII selects character density from cell brightness. Appearance → Particles → Dot matrix → Cell style switches the treatment. ASCII exposes Character spacing and Character inset, and retains its spacing separately from the dot grid. Unlit cells stay transparent. Appearance → Particles → Dot matrix controls this treatment; Emission width and Samples per path control the source that feeds the matrix. Base exposure sets the bias; Loudness response scales it with actual post-master RMS, with a 120 ms attack and 600 ms release. Voice count does not determine exposure. Older free-particle sizes are converted once on load/import.
- Appearance → Particles → Bloom controls intensity, radius and cutoff of the soft particle-only glow. Bloom does not affect the ring, text or smooth voice curves. Appearance → Particles → Paths & motion controls broad, continuous wave speed and amplitude, particle travel speed, path count, curvature, disorder, spread, depth and release behavior. Slow waves evolve continuously while the source and destination stay anchored. Phase is integrated so changing speed does not jump the paths. The shared field sits behind all panel artwork and controls; panels retain their transparent fills.
- Crosshair movement also pulls a damped elastic field: the paths lag behind the drag, carry a disturbance toward the ring, and settle after release. Drag influence, Wave tension and Drag damping control this response. Input comes from the crosshair’s world-coordinate movement, so camera navigation and layout changes do not inject a false impulse. The matrix and both path endpoints remain anchored.
- Bright particle heads with fading wakes travel from the map crosshair into the ring core. Their rate follows BPM; doubling tempo doubles their travel speed without resetting position. Appearance → Particles → Paths & motion → Particle flow rate sets path traversals per beat: 0.25 crosses in four beats, and zero pauses travel. Ambient wave speed and elastic drag remain independent. Inside the ring viewport, its resolved scene depth places the particle layer at the depth of the ring’s geometric center: particles cover rear beads and are hidden by front beads. Matrix color and bloom bypass ring-only grading. The Canvas2D upload, depth composite and transparent WebGL canvas use premultiplied alpha consistently, keeping faint glow and saturated particles continuous at the canvas edge. The depth mask removes both color and coverage behind front beads. Ring blur and color fringe normalize sampled transparency consistently so thin orbital guides retain their palette color. The Canvas2D fallback uses the same rear-beads → particles → front-beads drawing order. UI controls and annotations remain above the particle field. When the workspace changes size, the particle GPU texture is reallocated to the new canvas dimensions so the ring composite keeps animating.
- The galaxy combines spiral arms, a spherical core, sparse foreground stars and a distant field. Individual stars twinkle gently with seeded, staggered rhythms; Appearance → Galaxy → Star twinkle sets the amount. Landmark and nebula brightness remains steady, and Freeze or reduced motion stop ambient twinkling. Distance changes star size, brightness and softness, and orbiting reveals parallax between these layers. Appearance → Galaxy → Galaxy depth stretches only the star volume; tuning coordinates and sound stay fixed. Galaxy spread scales the field around a fixed world origin, so dragging the tuning crosshair never translates the stars. Explicit Pan still translates the view. Galaxy, sequence and envelope plots share the same transparent frame, stroke, radius and horizontal alignment.
- Galaxy guides adapt to zoom: closer views reveal finer divisions, and distant views blend into coarser divisions. The guides stay anchored to world coordinates. Guide spacing remains an adjustable density multiplier for Cartesian, orbital and dotted guides.
- The matrix treatment is independently implemented using the fixed-cell image sampling approach demonstrated by [udaign/matrices](https://github.com/udaign/matrices), particularly Wallpaper, ValueAliasing and PhotoWidget. No code or dependency from that repository is bundled.
- The compact green wireframe sphere shows the phase of the real filter LFO; its orbit extent responds to LFO depth. The second, accent-colored marker shows the tempo/arpeggiator clock: it circles once per eight beats normally, and follows arp rate/direction when enabled. Rate and depth change the sound and the visual response together. Modulation controls are also available in Sound on short displays.
- The white sequence contour shows step velocity; accent-colored nodes show pitch. Shift-drag changes velocity. White envelope geometry and its annotations show the configured ADSR; the accent-colored envelope trace responds to sounding voices.
- Sound controls visibly shape the ring even at rest: cutoff opens/lights the core, resonance sharpens its relief, waveform changes petal contour, and detune separates/twists layers. ADSR draws the inner profile; delay/feedback set echo arcs; reverb widens a soft halo. Sequence pitch, velocity, length and swing shape outer markers; tempo/arp drive a clock marker; Hold adds a latch bracket. While playing, real voice envelopes still drive the lit wedges.
- Signal uses the same inclined orbital guide lines as the other appearances. Guide opacity and spacing adjust them without changing camera framing. The hidden geometry bounds still reserve space for the ring’s full rotation, maximum bead breathing and sound response, keeping the ring inside the canvas throughout the zoom range. Camera distance stays independent of orbit angle and animation phase. Adjacent voice-sector envelopes blend continuously, without dark seams between equally lit regions. Individual bead sizes breathe with seeded independent phases and slightly different periods, without a collective ring pulse; Appearance → Ring → Motion exposes Bead breathing and Breathing rate independently of the musical tempo. Reduced motion disables ambient breathing, and Freeze holds its phase.
- Appearance includes dot-matrix size/count/glow, density, field depth/spread, signal weight, response, trails, ring geometry/material, grid, palette, contrast, glow, grain, and other controls. Freeze captures the ring and shared field while the audio continues.

## Validation

The collection regression suites cover independent Hold/Arp sources, audio-start cancellation, scheduled onset and release, voice limits and silence, grain bounds/windows/pool cleanup, radial hit mapping, FM derivatives, route and region editing, navigation ownership and state validation. The service-worker suite checks the full offline dependency graph, bounded installation, atomic installation failure and matching offline navigation shells. Browser checks also exercised all ten instruments with actual audio, simultaneous touches, switching, both floating panels, presets and landscape/portrait resizing. A native Chromium worker check installed all 40 assets, verified their bytes, deferred an update while playing, preserved unrelated caches, and opened all collection routes and Signal offline.

`node tests/tempo-control.test.mjs` checks relative pointer scrubbing, clamping, cancellation, concurrent pointers, keyboard handling and teardown. `node tests/visual-config.test.mjs` checks default migration, preservation of custom settings, other looks and sanitized values. `node tests/audio.test.mjs` checks scale mapping, asynchronous cancellation, sequencing, voice bounds, independent arpeggiation, timestamped visual envelopes, voice allocation, cancellation, filter LFO continuity, post-master RMS and scheduled touch provenance. `node tests/signal-field.test.mjs` checks exact trail endpoints, fixed-cell area sampling, ASCII peak sampling and character-density mapping, independent source size/count, grid masks and tone, selective particle bloom, Gaussian fallback, continuous motion, directional packet travel and BPM scaling, elastic propagation and settling, frame-rate-independent metering, freeze, silence and extreme geometry. `node tests/ring-hit.test.mjs` checks visible bead picking across camera orbit, rotation, tilt, perspective, scale, depth and geometry changes, plus cage containment, camera fitting, full rotation and zoom, continuous sector lighting, breathing, and material-anchored contact provenance through release and pointer reuse. Browser checks cover touch/mouse play and orbit classification, rotated ring picking, anchored trails, live Web Audio loudness response, matching plot frames, parameter editing, session persistence, responsive layouts and offline reload. Real iOS installed-mode audio and hardware frame rate need device validation.

`node tests/galaxy-grid.test.mjs` checks zoom-level continuity, world anchoring, manual spacing, cached geometry and guide rendering without WebGL. It also checks unrestricted pole crossings, projected crosshair alignment and fixed star positions while tuning across different galaxy spreads. Browser checks cover Cartesian, orbital and dotted guides through the zoom range. `node tests/touch-controls.test.mjs` checks secondary-touch button activation, cancellation and duplicate native-click suppression. Actual two-finger browser checks cover changing Hold without releasing the playing finger.

`node tests/pwa.test.mjs` checks fullscreen capability detection, browser-driven exits, unsupported and installed display modes, rejected requests, concurrent entry and teardown. For native GPU regression checks, serve the project and run `await (await import("./tests/rendering.browser.mjs")).runRenderingChecks()` in the browser console. This exercises production shaders with saturated alpha ramps, additive bloom, front/rear depth occlusion and translucent guide color, both with and without multisampling.
